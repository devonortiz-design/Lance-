# graphify

Source: https://github.com/Graphify-Labs/graphify (commit 5eedffa, branch v8)
License: Apache-2.0 (see LICENSE and NOTICE)

The skill installs its Python package (`graphifyy`) on first run.
Type `/graphify .` in Claude Code to build a knowledge graph of this repo.
Output lands in `graphify-out/`, which is ignored by git.
